# مكتبة أحكام — القضاء الإداري والإدارية العليا

برنامج استخراج وتصنيف الأحكام وإدارة الجلسات والأجندة.

- **الرابط:** https://hdorgham100-ctrl.github.io/maktabat-ahkam/
- يشتغل على الكمبيوتر والتابلت والموبايل، ويتثبت كتطبيق (📲).
- **التحديث تلقائي:** أي إصدار جديد يتنزل هنا بيوصل لكل المستخدمين أول ما يفتحوا البرنامج.
- **البيانات** (قاعدة الجلسات والأحكام) محفوظة على جهاز كل مستخدم فقط، ومش بتترفع هنا.

## إصدار جديد
1. استبدل `index.html` بالنسخة الجديدة (ورقم الإصدار جواها `APP_VERSION`).
2. زوّد رقم `version` في `version.json` بنفس الرقم واكتب الملاحظات.
